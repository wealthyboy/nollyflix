New contributor accounts created in admin or via video metadata receive a randomly generated 24-character temporary password. The login email can be auto-generated by leaving the email field blank when creating an account. Show pages display a masked password and use POST to reveal/copy only to admins. Reset button invalidates old password. No credentials are emailed by this code.

IMPORTANT: Existing auto-generated actor and filmmaker passwords cannot be recovered; use Generate/reset temporary password on their show pages.

Actor AND filmmaker logins now lead to a unified movie performance dashboard. On first login, all browser routes redirect a contributor to change the temporary password; its encrypted recoverable copy is then erased. Stats use existing film_events table from the 2026-11-22 migration; they are based on Nollyflix page clicks and watch starts, not third-party platform counts. Existing user/movie relationships must be correct for movies to appear. No films are automatically added to accounts.

Requirements: APP_KEY must remain stable for decrypting temporary credentials. Admin endpoints must only be accessible under existing admin middleware. Store/show password only over HTTPS. No production deploy or database migration was performed here.
